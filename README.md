# TUMDI

**Tube Saturation**  
by thesecondspeaker

Warm. Smooth. Musical.

TUMDI is a free boutique tube-saturation VST3 effect for macOS, designed for fast and musical tone shaping.

Use INPUT to push the saturation stage, DRIVE to add harmonic character and warmth, and OUTPUT to set the final level.

## Controls

- **INPUT** — Controls the level entering the saturation stage.
- **DRIVE** — Controls the amount of tube saturation and harmonic character.
- **OUTPUT** — Controls the final output level.

Double-click the DRIVE knob to return it to 50%.

## Download

Download the latest macOS release from the **Releases** section of this repository.

## Format

- VST3
- macOS
- Version 1.0

## Installation

Copy:

`TUMDI.vst3`

to:

`~/Library/Audio/Plug-Ins/VST3/`

Then restart or rescan plugins in your DAW.

This release is not Apple-notarized, so macOS may require additional approval when loading the plugin for the first time.
